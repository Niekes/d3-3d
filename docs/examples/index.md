# Examples

## In the documentation

- [Surface plot](/examples/surface-plot) — a radial wave drawn with `gridPlanes3D`, rotated by drag
- [Iso stack](/examples/iso-stack) — an exploded isometric architecture, drawn with `iso3D`
- [Office tower](/examples/iso-tower) — 24 floors of a city block, drawn with `iso3D`

## Embedding in your project

Include the UMD bundle via unpkg:

```html
<script src="https://unpkg.com/d3-3d/build/d3-3d.js"></script>
```
